# Roselt Invoice Generator

Roselt Invoice Generator is a lightweight, local-first invoicing app that runs in your browser. It helps freelancers and small businesses create polished invoices quickly — no account, no cloud required.

Key things you can do
- Pick a professional invoice template and preview it instantly.
- Edit your business details, client info, line items, taxes, discounts and notes directly on the invoice.
- Save and manage invoices locally (search, duplicate, delete).
- Filter invoices by status (Draft, Sent, Paid, Overdue) and export any invoice to PDF for sharing.

Why people like it
- Simple and focused — built for fast invoice creation without distraction.
- Private and local-first — your data stays in your browser.
- No installation required — open the app in a browser and start creating invoices.

Getting started (quick user steps)
1. Open `index.html` in a modern browser.
2. Choose `Invoices` from the sidebar to view or create invoices.
3. Click `New Invoice` (or choose a template), fill in the details, then click `Export` to download a PDF.
